Common Pitfalls to Avoid
❌ Unprofessional Repository Names - Using nicknames, random numbers, or informal terms

❌ Inaccessible Repositories - The #1 issue: students submit links that don't work

Solution: Test your link in an incognito browser before submission
❌ Missing Actual Notebooks - Uploading only PDFs or HTML exports instead of .ipynb files

Solution: Upload your actual Jupyter notebook files
❌ Notebooks Without Outputs - Uploading notebooks where cells haven't been run

Solution: Run all cells in your notebook before uploading so outputs are visible
❌ Uploading Large Public Datasets - Adding MNIST, CIFAR-10, etc. to GitHub

Solution: Just document the dataset name and source in your README
❌ Poor Organization - Unclear repository structure makes navigation difficult

Solution: Use clear folder names and include README files in each directory
❌ Insufficient Documentation - Notebooks with no markdown explanations or README files

Solution: Add markdown cells explaining what each section does and why
❌ Incomplete Work - Uploading partial projects without proper implementation

Solution: Only include projects you've completed, even if it's fewer projects
❌ Broken Links - Links in README files that don't work

Solution: Test every link you include
