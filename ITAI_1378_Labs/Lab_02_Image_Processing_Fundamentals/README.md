# Lab 02: Image Processing Fundamentals

## Problem Statement
This project helps to understand Image Processing. Computers see any image like one matrix with numbers. I want to change these numbers.

## Approach
I use Python to process images. I write code to change pixels. I test hardware acceleration with one Tesla T4 GPU.

## Results
I changed RGB images to grayscale. I applied some basic filters. I saved result images in `results` folder. This code runs fast with GPU.

## Key Findings
I learned how image works. One image equals one large array. Math operations change this array. OpenCV can process arrays very fast.
